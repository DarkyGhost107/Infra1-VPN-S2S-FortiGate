# Running-configs

| Archivo | Equipo | Cómo se obtuvo |
|---|---|---|
| `FGT-A_backup.conf` | FortiGate Sitio Usuarios | GUI: admin > Configuration > Backup |
| `FGT-B_backup.conf` | FortiGate Sitio Servidor | GUI: admin > Configuration > Backup |
| `ISP_running-config.txt` | Router ISP (Cisco) | `show running-config` |
| `SW-USUARIOS_running-config.txt` | Switch de usuarios (Cisco IOSvL2) | `show running-config` |

Las contraseñas y la pre-shared key de la VPN aparecen cifradas (`ENC`) en los backups de los FortiGate.
